# Автоматизация работы с Facebook

Инструмент для публикации подготовленных материалов в Facebook по запросу других сервисов. Сервис очередей публикаций и другие клиенты определяют, что и когда отправлять; этот проект отвечает за выполнение публикации и передачу результата вызывающему сервису.

Первая версия запланирована как CLI `facebook-publish` для публикации готового Reel в личный профиль через Camoufox. Спецификация находится в [плане Facebook](https://gitlab.com/reforms-lab/root/-/blob/main/docs/publishing/facebook.md) и [общем контракте издателей](https://gitlab.com/reforms-lab/root/-/blob/main/docs/publishing/contract.md): проверка аккаунта и аудитории Public, постоянный профиль, JSON-результат и защита от повторной отправки. Сейчас работающего механизма публикации еще нет; реальная проверка потребует согласованного тестового аккаунта, видео и подписи.

Версия проекта указана в `VERSION`; изменения фиксируются в `CHANGELOG.md`.
